# Farmers Market Database Application

## Overview

This project is a database-driven Farmers Market application developed as a group project.

The application will provide a graphical user interface that allows users to browse farmers markets, view market and vendor information, search for products, and place product pre-orders.

The application will connect directly to our relational database and demonstrate the complete life cycle of database design and implementation.

## Required Application Features

The completed application will allow users to:

* Browse a list of farmers markets
* View details for an individual farmers market
* View vendors associated with a farmers market
* Search for products across all farmers markets
* Place a product pre-order
* Process the pre-order using a database transaction
